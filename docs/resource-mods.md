# RML 模组

「皮肤 → RML 模组」用于安装 ResourceModLoader（RML）格式的资源替换模组：把 ZIP 里的 `.bundle` 文件落到游戏目录，并改写游戏读取的 Addressables catalog，让对应资源指向模组包。

## 使用

1. 退出游戏。
2. 打开「皮肤 → RML 模组」，点「导入资源模组 (.zip)」选择 RML 模组包。
3. 进度面板会显示当前阶段、百分比、正在处理的文件和引擎日志；解析较慢的模组可以「暂停 / 继续」。日志文本可以用鼠标选中复制，也可以点「关闭 / 打开」收起或展开。
4. 导入完成后会自动应用；也可以在之后点「应用模组」手动写入。
5. 中途点「取消并还原」会停止当前操作，把 catalog 恢复到此前的状态并删除临时文件。
6. 启动游戏查看效果。

停用某个模组后，Toys 会按剩余已启用的模组重新生成 catalog；删除最后一个已启用的模组时会自动恢复原版 catalog。

## 生效条件

- 游戏必须处于退出状态。游戏运行中只能导入，不能应用或启停已应用的模组。
- 首次使用前至少启动过一次游戏，让客户端下载 `catalog_<版本>.json`。
- 游戏资源版本更新后（例如 3.3.0 → 3.4.0），需要重新点「应用模组」；界面会提示「有改动待应用」。
- Steam 的「验证游戏文件完整性」会还原安装目录里的 `catalog.bundle`，之后同样需要重新应用。

如果应用后没有任何替换写入 catalog，页面会提示失败并列出引擎错误，不会显示为已应用。为旧资源版本制作的模组包（包内 bundle 名与当前资源版本不一致）可能只有一部分资源能生效，其余条目会以警告或错误列出。

## 数据位置

| 内容 | 位置 |
| --- | --- |
| 模组包与清单 | 游戏目录下的 `AstralParty_ResourceMods\packages\`、`installed.json` |
| catalog 备份 | 游戏目录下的 `AstralParty_ResourceMods\backup\<资源版本>\` |

「还原官方资源」会把当前资源版本的 catalog 备份写回游戏；模组文件仍保留，方便再次应用。卸载 Toys 不会自动撤销已经应用的资源替换，需要先在页面里还原官方资源。

## 支持范围
安装器内置 [ResourceModLoader](https://github.com/zxy19/ResourceModLoader) 引擎（MIT），由它解析包内容：

- .bundle 直接替换、eplace.txt、mod.json 的 Add / Redirect / Bundle / Patch
- WrapType: text / WrapType: image（现场生成 AssetBundle）
- 图片直接放入 mods 目录、嵌套 ZIP
- 包内 bundle 名与当前版本不一致时，按资源内容反查官方 bundle

与 RML 一致：Patch 目标 bundle 必须存在于当前安装或下载缓存中，否则该条 patch 不会生效；包内资源版本与游戏不一致时也可能只应用一部分。

模组包的内容与版权归各模组作者所有，使用、修改和二次分发请遵守包内附带的授权协议与说明；未明确授权的模组包请勿分发。

## 与 CesiumLoader 模组的关系

资源模组改的是 Addressables 资源本身；CesiumLoader 的角色皮肤、卡牌皮肤是在运行时替换贴图。两者作用于不同层，同名资源同时存在时，通常以运行时替换的结果为准。建议同一套外观只选一种方式，避免难以判断哪一层在生效。
