# CesiumLoader 2.5.0

发布日期：2026-10-15

- 适配《吉星派对》3.3.0 / Unity 2022.3.62f3，使用新版游戏程序集重新编译 SDK 和全部 7 个内置模组。
- 修复游戏文本枚举变化导致的卡牌、筹码、技能及占卜名称查询错位。
- 默认皮肤包刷新为 196 张官方卡面，补齐建筑卡及地图事件的普通/SFW 图片；默认皮肤继续作为独立附件提供。
- 角色皮肤适配 Unity 2022 资源基线。
- 修正 CombatOddsMod 的普通攻击预测：普通命中最低造成 1 点伤害。
- 加载器、SDK 和 CLI 版本统一为 2.5.0；分发 DLL 与同次构建 PDB 成对更新。

加载器、默认皮肤与 SDK 工具包各提供版本化文件名及固定文件名，共 6 个附件。
