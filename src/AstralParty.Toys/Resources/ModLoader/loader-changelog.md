# 更新日志 / Changelog

本文件按版本记录 `CesiumLoader` 的功能变更。版本号与 GitHub 发布 tag 一一对应（如 `modloader-3.3.2`，版本号为 `3.3.2`），发布产物由 [release-modloader.yml](.github/workflows/release-modloader.yml) 在打 tag 时自动构建。

## [3.6.0] - 2026-11-10

### Unity 加速与回合时钟

- SpeedHackMod 新增 `accelerationMode=unity`，通过 Unity 时间缩放加速，原有 `native` 模式继续保留；缺少该配置项时仍使用 `native`。
- Unity 模式同步 FairyGUI 界面、独立计时动画、镜头切换与可适配的静音 UI 视频；静音视频最高 3 倍，带音轨或音轨信息未知的视频不强行改速。
- 新增固定更新步长优化，可通过 `optimizeFixedUpdates` 关闭；切换模式、恢复 1 倍或卸载时释放本模组仍持有的动画与时间设置，不主动解除游戏暂停。
- TurnClockMod 适配 Unity 与原生组合倍率，按计时器使用的时间来源补偿自己的操作倒计时、选人、结算、房间等待与剧情自动播放。

### 变速与控制台

- 变速控制改用每进程独立的本机 UDP 端口，设置请求与实际倍率回执均不再使用共享通信文件；多开时互不串号。
- SDK 新增 `SpeedHack.TryGetSpeed`，区分已确认倍率与未知状态；SpeedHackMod 和 TurnClockMod 使用 UDP 状态确认，兼容倍率切换、请求重试及回执过期。
- 控制台标题显示加载器版本与构建时的 Git 短哈希，进入或退出 Debug Shell 时保留版本标识；包含未提交源码更改的构建附带 `-dirty` 标记。
- 升级时需同时更新原生加载器、SDK、SpeedHackMod 与 TurnClockMod；旧文件通道不再作为备用通道，现有倍率与热键配置保留。

## [3.5.2] - 2026-11-09

### 多开

- **修复多开共图冷启时地图加载偶发停在 90%**：多个实例共用同一份地图资源、冷启第一次进图时同一缓存文件会被同时打开，打开失败会让加载直接停在 90% 且需重启进程才好。加载器现在对这类瞬时占用自动重试，加载过程可继续进行；失败与恢复状态会写入加载器日志（`bundle CreateFileW`），便于排查。设置与用法不变。

### 内置模组

- **`CombatOddsMod` 2.8.4**：梅加斯理论伤害读数与玩家头顶攻防标签新增位置/字号微调（`MegasDamageOffsetX/Y`、`MegasDamageFontSize`、`PlayerAttrOffsetX/Y`、`PlayerAttrFontSize`），在 Toys 配置中调整后热重载生效；默认与旧版位置、字号一致。

## [3.5.1] - 2026-11-08

### 变速引擎：修复高频时钟调用下的无响应

- **修复变速时钟的全局自旋锁（关键）**：虚拟时钟状态原本用 56 字节的 `TimeState` 整体做原子拷贝，MSVC 里超过 16 字节的 atomic 拷贝要走全进程共用的自旋锁（`_Atomic_lock_acquire`）。游戏高频调用 `QueryPerformanceCounter` / `GetTickCount`，几十个线程会排在同一把锁上自旋，主线程饥饿后任务管理器显示未响应，画面冻结但声音还在。现把状态拆成逐字段的 ≤8 字节无锁原子，hook 入口不再取锁；切速顺序（基准先行、速度最后发布）保证撕裂读误差只有微秒级，变速手感与连续性不变。
- **建议**：从 3.5.0 以前版本升级的用户，若曾在战斗中遇到“画面冻住、声音还在”的无响应，升级到 3.5.1 后正常对局不应再复现；倍率与时钟行为不变。

## [3.5.0] - 2026-11-08

### SDK：玩家与对局上下文

本版新增均为只加不改：不改现有方法签名、不改现有事件语义与触发条件，旧 mod 无需重新编译即可继续运行。

- **名册**：`PlayerStat` 新增 `Slot`（座位号，0 起，异常时按名册顺序兜底）与 `Character`（角色名，缺失为空串）。
- **模式分数**：新增 `Players.Score(playerId)`，读取当前 `SpecialScore`，查不到返回 0。
- **对局上下文**：新增 `Players.TryGetMatch(out MatchInfo)`，一次拿到是否在有效对局、房间 id/开始时间（两者同时不变视为同一局）、地图模式与是否 PVE/已入战斗；大厅与战斗未就绪时返回 `false`。
- **名字开关**：`Names.Card/Relic/Skill` 新增 `(id, withId)` 重载，`withId=false` 只返回名字；原单参签名与输出保持不变。
- **配置读取**：新增 `ConfigReads.SkillParam(skillId, index)`（越界/缺失返回 `-1`）与 `ConfigReads.RelicQuality(relicId)`（0=无/1=蓝/2=紫/3=橙）。
- **商店单价**：`ShopOffer` 新增 `UnitPrices`，与卡牌逐张对齐（未知为 `-1`，PVP 恒 `-1`）。

### SDK：结算、追击与累计步数

- **完整血量**：新增 `GameEvents.HeroHpChangedFull`（`HeroHpChangeInfo`，含归属与原始值），与旧 `HeroHpChanged` 并行广播；`RealHp == 0` 表示未提供。
- **结算数据**：新增 `GameEvents.MatchSettled`（每人 `PlayerFinalStats`，服务器最终值），只做对账不覆盖本地累计。
- **追击快照**：新增 `GameEvents.FightResolved`（`FightSnapshot`），按 `BattleId` 去重推送攻防/追击归属。
- **累计步数**：新增 `GameEvents.MovementTotalChanged` 与 `GameEvents.MovementTotal`（按到达确认计数，查不到返回 `-1`）。

### 内置模组

- **新增 `MapPeekMod`（选人地图预览）**：选人/选皮肤/准备阶段在左上角显示本局地图名、地图 ID、模式、难度与人数，开赛后自动隐藏；纯只读。
- **`ShopRelicPeekMod` 1.3.0**：商店/筹码看板每条信息追加相对时间（`刚刚 / Xs前`，可分别开关）；玩家名后显示所选角色名（可关）；修复离店不自动关闭：PVP 空包关店、PVE 回执 `IsClose`、商人快照直达离店倒计时、新回合强制离店与在店保底过期（`max(60, 3×时长)`）共同兜底，`Sn` 去重避免重复广播复活已离店条目。

## [3.4.0] - 2026-11-08

### SDK：对局观测事件

`GameEvents` 新增商店成交、筹码刷新、血量差值与击杀等事件，并改为按需挂钩：只有存在订阅者的 RPC 才被包装，订阅者清空后还原原回调。

- **商店成交**：新增 `GameEvents.ShopSettled`，参数 `ShopSettlement`，覆盖 PVE 5216 与 PVP 5030。提供本次实际购买的槽位、成交消息自带的卡牌、已买标记、离店状态、PVE 转账目标与下行序号；`ResolveBoughtCardIds()` 把槽位下标换算成卡牌配置 id。
- **商店报价**：新增 `GameEvents.ShopOffered`，参数 `ShopOffer`，在 `ShopCandidates` 的卡 id 列表之外保留原价、折扣价、免费、已买与转账字段；`TotalGold` 返回应付款（有折扣时取折扣价）。
- **筹码候选与结果**：新增 `GameEvents.RelicOffered`（`RelicOffer`，含 `Sn`、`IsReroll`、`Lv`、`SupLv`）与 `GameEvents.RelicResult`（`(playerId, relicId, isReroll)`）。`RelicSelected` 保持“只报真正选定”的原有语义。
- **筹码刷新次数**：新增 `GameEvents.RelicRerollChanged` 与 `GameEvents.RelicRerollRemaining(playerId)`；查不到时返回 `-1`。
- **血量与击杀**：新增 `GameEvents.HeroHpChanged`（差值为正可负）与 `GameEvents.PlayerKilled`（`victimId, attackerId`）。
- **下行序号**：新增 `GameEvents.DownSn(int command)` 与 `GameEvents.DownSn(RPCMsgManager, int)`，配合 `GameCommands` 常量在结果事件里同步读取对应消息的下行序号，用于和候选 action 的 `Sn` 对账。
- **挂钩行为**：`StartAutoHook()` 仍可一次启动内部维护；所有事件改为逐订阅者 `try/catch`，单个 mod 抛异常不影响游戏与其它订阅者。已有事件签名与语义保持不变。

### SDK：uGUI 控件封装（WidgetService）

- 新增 `WidgetService`（`Canvas` / `Panel` / `Text` / `Slider` / `Badge` / `Anchor` / `Stretch` / `Place` / `Destroy` / `DestroyAll` / `EnsureEventSystem`）：SDK 编译期只引用 `UnityEngine.CoreModule`，运行时按名解析 uGUI 类型，缺失时返回 `null` 并在 `UnavailableReason` 给出原因；所有创建/销毁/改属性自动切主线程。`WidgetHandle` 暴露 CoreModule 的 `Rect`（`RectTransform`）与底层 `Component`，常用操作走 `SetText` / `SetValue` / `SetColor` / `SetActive` / `SetRaycastTarget` / `SetSize` / `SetAnchoredPosition`；`WidgetScope` 记录根节点，`Dispose()` 逆序销毁，配合 `ctx.RegisterCleanup` 保证卸载清理。用法见 `docs/SDK-UI.md` 第 9 节。
- 新增源码示例 `WidgetProbeMod`：在屏幕右上角用 `WidgetService` 画一个常驻 HUD 面板，订阅本版全部新事件（商店报价/成交、筹码候选/结果、刷新余量、血量差值、击杀）并把原始字段与名字渲染到面板上；`F9` 显隐、`F8` 清空。该示例不随加载器内置包分发。

## [3.1.3] - 2026-11-04

### 启动与主线程调度

启动阶段的等待与调度做了收敛，体感上主要体现在进入游戏与切换界面时：

- **共享就绪探测**：所有模组共享一次「游戏已可玩」的探测，不再每个模组各跑一份轮询；日志里只会出现一条 `游戏已就绪: 启动门等待 …`。
- **各自上限继续生效**：每个模组仍按自己的等待上限初始化，不会被等待时间最长的模组拖住。
- **兜底不卡死**：探测若提前结束（异常、主线程泵尚未就绪），等待中的模组会直接在自己的上限处继续初始化，不会停在启动门。
- **主线程识别自愈**：主线程 ID 只从 UniTask PlayerLoop 或帧泵线程确认；记录不正确时会自动更正，避免误把后台线程当主线程后出现调度延迟。
- **主线程调度自等待保护**：若等待排空的线程本身就是主线程，超过 100 ms 立即放弃并报告，不再等到超时让画面停住。

### 原生音频通道改为硬编码关闭

- 原生音频服务（UDP 端口 + `<audio>` 文件通道 + MCI 播放）改由加载器代码常量控制，当前固定关闭；`doorstop_config.json` 的 `audioControlEnabled` 仍会被读取与保留，但不再决定是否启动。
- 影响：**自定义音效 / BGM 替换不可用**（例如 AudioSkinMod 的音效方案）。游戏本体的音乐与音效不受影响。
- 加载器通过 `CESIUM_AUDIO_ENABLED` 告知 SDK 真实状态，并清理上一次运行遗留的 `port.txt` / `state.txt`，避免音效请求发往旧端口后静默丢失。
- 调试 Shell 中执行 `set audioControlEnabled true` 会提示该通道已在代码中关闭。

### 音频子系统开销

- 原生音频控制通道改为事件驱动（目录变更通知 + 兜底周期重读），空闲时不再持续打开请求文件；通知句柄创建失败的目录自动退回轮询读取。重复播放同一音效时复用已加载的 MCI 槽位。
- SDK 侧：未注册任何替换规则且没有事件订阅者时，声音事件直接放行；`configId → 事件名/事件 ID` 的结果做缓存；替换规则查询改为无锁读取；Unity 音频接口绑定日志只输出方法数量，不再拼接全部方法签名。

### 内置模组

- **角色半透明（CharacterTransparencyMod）**：按住热键时不再每帧遍历角色层级，只维持已修改过的渲染器透明度，降低持续按住时的开销。
- **星币商店助手（StarCoinShopMod）**：缓存 UI 管理器查询，并在面板关闭时释放，减少每帧重复查找。

## [3.1.1] - 2026-11-03

### 新增内置模组：角色半透明助手（CharacterTransparencyMod）

- 按快捷键 `H`（默认）使游戏中的角色半透明化（默认 36% 不透明度），方便在角色堆叠或处于关键地块时清晰查看下方地块图标、事件与怪物信息。
- **触发模式开关**：提供 `holdMode` 开关，支持「长按切换」（按住半透明、松开恢复）与「点击切换」（按一次开启、再按一次恢复），默认为长按模式。
- **自定义不透明度**：支持在配置中自定义目标不透明度（`opacity`，范围 0.0 ~ 1.0 或 0 ~ 100%）。
- **技能兼容与透明度还原**：松开或切回时精准还原角色原本的透明度，与角色隐身技能（如邦妮、修女）互不冲突。
- **输入保护**：处于聊天输入框或文本聚焦状态时不响应热键。
- 随包配置带完整多语言注释（简中、繁中、英文、日文），Toys 配置界面可直接捕获修改快捷键与参数。

### SDK 路径服务（CesiumLoader.SDK.IO.Path / SdkPath）
